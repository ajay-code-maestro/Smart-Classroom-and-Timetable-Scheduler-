# Smart Classroom and Timetable Scheduler

A web-based application for managing classrooms, faculty, subjects, and generating timetables efficiently.

## Features
- Admin, Faculty & Student Dashboards
- Classroom Management
- Faculty & Subject Management
- Automatic Timetable Generation
- Secure Authentication

## Tech Stack
- **Frontend:** React.js, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MySQL

## Installation

```bash
git clone https://github.com/ajay-code-maestro/Smart-Classroom-and-Timetable-Scheduler.git
cd Smart-Classroom-and-Timetable-Scheduler

# Backend
cd backend
npm install
npm run dev

# Frontend
cd ../frontend
npm install
npm start
```
